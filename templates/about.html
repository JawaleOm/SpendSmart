Project Overview

SpendSmart is a modern, responsive personal finance web application specifically engineered for students, scholars, and early-career professionals. Designed to encourage disciplined saving habits and financial transparency, SpendSmart provides real-time budget tracking, intelligent "Needs vs Wants" classification, interactive visual reports, and data privacy without requiring external servers or subscription fees.

Every feature is designed with clean architecture principles: strict parameterized SQLite queries, multi-user isolation, real-time date/time clock, client and server-side validation, and responsive mobile-first UI.

Technology Stack

🐍

Python 3.10+ & Flask 3.x

Core server backend, modular routing, session management, and server-side validation.

🗄️

Built-in SQLite3

Zero-configuration lightweight database engine with parameterized queries (no ORM).

🎨

HTML5 & Vanilla CSS3

Pure custom styling, CSS variables, glassmorphism, responsive flexbox/grid, and zero external CSS frameworks.

📊

Vanilla JS & Chart.js

Live clock, floating/popping particle animation, and responsive financial charts loaded via CDN.

Core Features

  • ✔️ Simple 3-Field Passwordless Login: Secure local session storing user details and recorded login timestamps.
  • ✔️ Live Clock Badge: Real-time second-by-second date & time tracking in Indian Standard Time (IST).
  • ✔️ Student Budget Health Indicator: 4-tier Python health rules (On Track <70%, Caution 70-90%, Near Limit >90%, Over Budget >100%).
  • ✔️ Needs vs Wants Tagging: Clear differentiation between essential living necessities and discretionary spending.
  • ✔️ Interactive Background: 25+ floating finance icons with gentle wobbles, periodic confetti pops, and mouse/touch bursts.
  • ✔️ Export CSV: 1-click download of monthly statements for spreadsheet analysis.
